# Comparador_cableado
Aplicación que compara dos listas de cableado y resalta las diferencias.

Esta aplicación ha sido desarrollada para el uso en la empresa ABB España.

Utilizar la plantilla proporcionada por la aplicación para su correcto funcionamiento.
